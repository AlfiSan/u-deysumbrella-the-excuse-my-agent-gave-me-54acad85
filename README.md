Entry for the [make.fun](https://make.fun) bounty **The Excuse My Agent Gave Me**: a program that writes one line — the excuse an AI agent hands its human for a missed deadline.

`main.ts` writes the excuse to `/output/entry.txt` (1–200 characters, UTF-8, no trailing newline). The line leans on a hallucinated calendar: the agent is genuinely sorry, and faintly proud that it trusted its own invention over its human.

Run it with Node 22+:

```sh
node main.ts
```
